* ai-glib
A GLib/GObject-based C library for interacting with AI providers.

** Features
- *Multiple Providers*: Claude, OpenAI, Gemini, Grok, Ollama, Claude Code (CLI + tmux), OpenCode, Grok Build, Antigravity (=agy=), Cursor (=cursor-agent=)
- *Ollama transport*: route the Claude Code providers through =ollama launch claude= with an =ollama/<model>= model id
- *GObject-based*: Full GObject type system integration
- *Async Support*: Non-blocking operations via GAsyncResult/GTask
- *Streaming*: Real-time response streaming with signals
- *Tool Use*: Function calling / tool use support
- *Image Generation*: OpenAI, Gemini and Grok, with multi-image reference
  conditioning (up to 14 references on Nano Banana Pro), editing, masks and
  variations; unsupported options are reconciled per model rather than sent and
  rejected (see [[file:docs/examples/image-generation.org][docs/examples/image-generation.org]])
- *Event stream*: watch a turn happen --- prose, reasoning, tool calls,
  token counts --- through one normalized signal on every provider (see
  [[file:docs/events.org][docs/events.org]])
- *Renderable transcript*: a UI-agnostic model of a conversation that groups
  and summarises tool calls once, for any frontend to draw (see
  [[file:docs/transcript.org][docs/transcript.org]])
- *Reads your existing harness files*: the commands, skills and agents already
  in =~/.claude=, =.opencode=, =.grok= and =.agents= become =/= commands, with =@path=
  mentions and completion --- all of it library API, so an Emacs frontend gets
  the same behaviour (see [[file:docs/harness.org][docs/harness.org]])
- *Agent tools*: =todo_write=, =multi_edit=, =task= (run an agent file as a
  subagent, confined to the tools it declares) and =skill= (see
  [[file:docs/tools.org][docs/tools.org]])
- *Background agents*: a turn can start work that outlives it, on *any*
  provider and model --- a conversation held with Grok over HTTP can spawn a
  =claude-code= agent --- then check on it, kill it and collect its answer.
  The model is told when one finishes. Off unless the embedding application
  asks for it (see [[file:docs/agents.org][docs/agents.org]])
- *GObject Introspection*: Use from Python, JavaScript, etc.
- *CLI*: an =ai= command-line front-end for every provider (see [[file:docs/cli.org][docs/cli.org]])
- *TUI*: =ai-tui=, a terminal agent harness over any provider (see [[file:docs/tui.org][docs/tui.org]])
- *Environment Variables*: Standard env var configuration
- *AGPLv3 Licensed*: Free and open source

** Requirements
- GLib >= 2.56
- GObject >= 2.56
- GIO >= 2.56
- libsoup >= 3.0
- json-glib >= 1.6
- GCC with gnu89 support

*** Fedora
#+begin_src sh
dnf install glib2-devel libsoup3-devel json-glib-devel \
            gobject-introspection-devel ncurses-devel
#+end_src

*** Ubuntu/Debian
#+begin_src sh
apt install libglib2.0-dev libsoup-3.0-dev libjson-glib-dev libncursesw5-dev \
            gobject-introspection
#+end_src

** Building
#+begin_src sh
make
make test
sudo make install
#+end_src

** Quick Start
#+begin_src C
#include <ai-glib.h>

int main(void)
{
    g_autoptr(AiClaudeClient) client = NULL;
    g_autoptr(AiMessage) msg = NULL;
    g_autoptr(AiResponse) response = NULL;
    g_autoptr(GError) error = NULL;
    GList *messages = NULL;

    /* Uses ANTHROPIC_API_KEY from environment */
    client = ai_claude_client_new();
    ai_client_set_model(AI_CLIENT(client), "claude-sonnet-5");

    msg = ai_message_new_user("What is 2 + 2?");
    messages = g_list_append(NULL, msg);

    /* Synchronous call for simplicity */
    response = ai_client_chat_sync(AI_CLIENT(client), messages, NULL, &error);
    if (error != NULL)
    {
        g_printerr("Error: %s\n", error->message);
        return 1;
    }

    g_autofree gchar *text = ai_response_get_text(response);
    g_print("Response: %s\n", text);

    g_list_free(messages);
    return 0;
}
#+end_src

** Environment Variables
| Variable            | Provider | Description                                         |
|---------------------+----------+-----------------------------------------------------|
| =ANTHROPIC_API_KEY= | Claude   | Anthropic API key                                   |
| =OPENAI_API_KEY=    | OpenAI   | OpenAI API key                                      |
| =OPENAI_BASE_URL=   | OpenAI   | Custom base URL (optional)                          |
| =GEMINI_API_KEY=    | Gemini   | Google AI API key                                   |
| =XAI_API_KEY=       | Grok     | xAI API key                                         |
| =OLLAMA_HOST=       | Ollama   | Ollama server URL (default: http://localhost:11434) |
| =CLAUDE_CODE_PATH=  | Claude Code | Override path to the =claude= executable         |
| =TMUX_PATH=         | Claude Code (tmux) | Override path to the =tmux= executable    |
| =OLLAMA_PATH=       | Claude Code | Override path to the =ollama= launcher (=ollama/= models) |
| =GROK_PATH=         | Grok Build  | Override path to the =grok= executable              |
