#+TITLE: Typed decisions with Laya

Laya is one =AiDecider= backend. The request types, the front-ends and the other two backends (TypeSafe Jev and Ollama) are documented in [[file:decisions.org][Typed decisions]].

=-p laya= still selects this client. With no =-p=, Laya is selected only when =LAYA_BASE_URL= is set and =TYPESAFE_API_KEY= is not. =AiLayaClient= does not read those variables itself. =ai decide= and =/decide= do, and they pass them as =base-url= and =api-key=.

#+begin_src sh
ai decide -p laya -m english -q 'Is this spam?' 'Win a prize'
LAYA_BASE_URL=http://127.0.0.1:8000 ai decide -q 'Is this spam?' 'Win a prize'
#+end_src

State is text. Boolean questions do not take criteria. There is no box question and no image payload. Checkpoints are =english=, =multilingual= and =typed-decisions=. The client default origin, used when =-p laya= is set and no URL is passed, is =http://127.0.0.1:8000=.

=examples/decide-spam.c= is the small C program. It does not install a server.

#+begin_src sh
make build/release/examples/decide-spam
LAYA_BASE_URL=http://127.0.0.1:8000 build/release/examples/decide-spam 'Win a prize!'
#+end_src
